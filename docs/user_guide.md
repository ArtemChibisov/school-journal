# Как пользоваться

Инструкция для работы в системе. Без команд и терминала — только то, что нажимается в браузере.

Адрес: `https://reports.projector-school.info`

Последнее обновление: 01.10.2026.

## 1. Вход

Открываешь адрес, вводишь логин и пароль. После входа слева появляется меню — через него доступно всё.

Если забыл пароль, сам его не восстановишь: меняется командой на сервере. Пиши разработчику.

Выйти — кнопка «Выйти» справа сверху.

## 2. Проверка по классам

Главная операция. Система открывает журналы всех классов и смотрит, что в них заполнено, а что нет.

### Как запустить

1. В меню слева — **«Классы и таблицы»**.
2. Сверху кнопка **«Проверить дескрипторы, критерии и оценки»**. Нажимаешь, открывается страница проверки.
3. Наверху страницы поле **«Класс»**. Два варианта:
   - **«Все активные классы»** — проверить всё. Так делается обычно.
   - Выбрать один класс — когда нужно быстро проверить что-то одно.
4. Нажимаешь кнопку **«Проверить дескрипторы, критерии и оценки»**.

Всё. Дальше система работает сама.

### Что происходит дальше

Появляется синяя плашка «Проверка выполняется. Страница обновляется автоматически». Страница сама
перезагружается каждые 10 секунд — ничего нажимать не надо.

Все 32 журнала нужно скачать из Google и разобрать лист за листом. Это несколько минут. Можно уйти
и вернуться: проверка не прервётся, если закрыть вкладку.

Когда закончится, на странице появятся карточки с числами: сколько классов проверено, сколько
предметов, сколько проблем.

### Куда уходит результат

Система **сама записывает результат в Google-таблицу мониторинга**. Руками переносить ничего не надо.

Запись идёт с заменой: что проверили, то в таблице и окажется. Поэтому если проверить один класс,
в таблице останется только он. Полная проверка перезапишет всё целиком.

### Две кнопки запуска — не перепутай

На странице их две, и работают они по-разному:

| Кнопка | Где | Что делает |
| --- | --- | --- |
| «Проверить дескрипторы, критерии и оценки» | Наверху, рядом с полем «Класс» | Проверяет **то, что выбрано** в поле «Класс» |
| «Запустить сейчас» | Ниже, в блоке «Автопроверка» | Запускает **обычную полную** проверку, минуя поле «Класс» |

Если нужен конкретный класс — только верхняя кнопка.

## 3. Как читать отчёт

В меню слева — **«Отчёт заполненности»**.

Если написано «Проверки ещё не запускались» — значит ни одна проверка не доходила до конца.

Страница показывает **один выбранный запуск**. Сверху список «Запуск JobRun» — через него смотрят
предыдущие проверки. По умолчанию открывается последняя.

В таблице по строке на каждый предмет каждого класса: учитель, класс, предмет, модуль, статус
заполненности и ссылка на саму таблицу журнала. Ссылка рабочая — можно сразу открыть журнал и
посмотреть глазами.

Ниже отдельный блок **«Не заполнены дескрипторы»** — то, на что надо реагировать.

Кнопка **«Экспорт CSV»** выгружает то, что сейчас на экране, с учётом фильтров.

## 4. Напоминания преподавателям

На странице отчёта есть кнопка **«Отправить напоминания преподавателям»**.

**Она отправляет настоящие сообщения настоящим людям в Telegram.** Не нажимай, чтобы «посмотреть,
что будет» — будет рассылка.

Перед нажатием стоит убедиться, что отчёт свежий и в нём нет мусора: если система чего-то не поняла
в журнале, учитель получит претензию на пустом месте.

## 5. Автопроверка по расписанию

На странице проверки есть блок **«Автопроверка дескрипторов, критериев и оценок»**. Там видно:

- включена ли она;
- с каким интервалом запускается;
- когда был последний запуск и когда будет следующий.

Если автопроверка включена, руками запускать обычно не нужно — отчёт обновляется сам. Переключатель
**«Включить автопроверку»** и поле интервала меняются там же, кнопкой «Сохранить».

Прежде чем запускать проверку руками, посмотри на «Последний запуск» — возможно, она только что
отработала.

## 6. Если что-то пошло не так

**Первое место, куда идти, — «Журнал событий»** в меню слева.

Это один список всего, что система делала в последнее время. По умолчанию показывает только ошибки
и предупреждения, за неделю. Сверху три числа за сутки: ошибки, предупреждения, запуски.

Ошибки написаны человеческим языком. Под каждой — строчка «Подробности для администратора», её
можно раскрыть и переслать разработчику.

Кнопка «Открыть» справа ведёт в тот запуск, где всё случилось.

| Что видишь | Что делать |
| --- | --- |
| Проверка прошла, но отчёт пустой | Журнал событий, выбрать задачу «Проверка заполненности журналов» |
| «Нет доступа к таблице» | «Google-подключение» → «Проверить доступы» |
| Класса нет в отчёте | «Журналы модуля» — проверить, нашёлся ли его журнал |
| Ничего не понятно | Журнал событий, «Показать все события», скинуть разработчику |

## 7. Начало учебного года

Порядок важен: каждый следующий шаг опирается на предыдущий.

1. **«Учебный год»** — создать год и вставить ссылки на таблицы и папки Google. Это единственное
   место, где живут ссылки; больше их нигде вписывать не надо.
2. **«Google-подключение»** → «Проверить доступы» — убедиться, что система видит все ссылки.
   Таблица из 13 строк покажет, где доступ есть, где ошибка, где не заполнено.
3. **«Состав классов»** → «Пробный прогон», посмотреть результат, затем «Импортировать». Пробный
   прогон ничего не меняет, его можно запускать сколько угодно.
4. **«Журналы модуля»** — указать даты модуля и папки с журналами, затем «Найти журналы» и, если
   всё нашлось, «Привязать к классам».
5. **Проверка по классам** — раздел 2 этой инструкции.

## 8. Карта экранов

| Экран | Зачем |
| --- | --- |
| Классы и таблицы | Список журналов по классам. Отсюда запускается проверка |
| Отчёт заполненности | Результат проверки |
| Отчёты на проверку | Отчёты учеников для вычитки |
| Таблица критериев | Все критерии, собранные из журналов |
| AI-вычитка критериев | Проверка формулировок нейросетью |
| Проблемные критерии | Что не прошло проверку |
| Whitelist критериев | Формулировки, заведомо считающиеся правильными |
| Контакты родителей | Кому отправлять отчёты |
| Запуски | История всех задач |
| Журнал событий | Что происходило и что сломалось |
| Учебный год | Все ссылки года в одном месте |
| Состав классов | Импорт учеников и тьюторов |
| Журналы модуля | Даты, папки и поиск журналов |
| Google-подключение | Есть ли доступ и проверка ссылок |

## 9. Чего система не делает

Чтобы не ждать напрасно:

- **не создаёт журналы** — пока только находит уже созданные руками;
- **не заполняет журналы за преподавателей**;
- **не знает, какие предметы должны быть в классе** — видит только то, что есть в журнале;
- **не отправляет напоминания сама** — пока только по кнопке.
