# Grafana / Loki / Alloy Cheat Sheet

This project sends server and Docker logs from `serverchibi2` to Grafana Cloud with Grafana Alloy.

Keep secrets out of chat, screenshots, git, and docs. Grafana tokens usually appear in:

- `/etc/systemd/system/alloy.service.d/env.conf`
- commands generated by Grafana Cloud during Alloy setup

If a token was shown in terminal output or screenshots, rotate it in Grafana Cloud.

## Current Setup

- Server: `serverchibi2`
- Project directory: `/opt/school_journal`
- Compose file on server: `docker-compose.server.yml`
- App port inside NAT/LXC: `127.0.0.1:8082`
- Alloy config: `/etc/alloy/config.alloy`
- Alloy service: `alloy.service`
- Grafana logs datasource: usually `grafanacloud-...-logs`
- Main log label: `compose_project="school_journal"`

Data path:

```text
Docker containers -> Grafana Alloy -> Grafana Cloud Loki -> Grafana Explore
```

## Server Checks

Check Alloy:

```bash
systemctl status alloy --no-pager -l
curl -fsS http://127.0.0.1:12345/-/ready
journalctl -u alloy -n 100 -l --no-pager
```

Check for Alloy errors:

```bash
journalctl -u alloy --since "10 minutes ago" -l --no-pager \
  | grep -Ei "error|warn|docker|permission|denied|timestamp|loki|school_journal"
```

Check project containers:

```bash
cd /opt/school_journal
docker compose -f docker-compose.server.yml ps
docker compose -f docker-compose.server.yml logs --tail=100 web
docker compose -f docker-compose.server.yml logs --tail=100 scheduler
```

Generate fresh app logs:

```bash
curl -fsS http://127.0.0.1:8082/healthz
curl -fsS http://127.0.0.1:8082/readyz
```

## Grafana Explore

Open:

```text
Grafana -> Explore -> datasource: grafanacloud-...-logs
```

Use time range `Last 15 minutes` when checking fresh logs.

All project logs:

```logql
{compose_project="school_journal"}
```

Only web:

```logql
{compose_project="school_journal", compose_service="web"}
```

Only scheduler:

```logql
{compose_project="school_journal", compose_service="scheduler"}
```

Only PostgreSQL:

```logql
{compose_project="school_journal", compose_service="db"}
```

Only proxy:

```logql
{compose_project="school_journal", compose_service="proxy"}
```

Errors:

```logql
{compose_project="school_journal"} |~ "(?i)error|exception|traceback|failed|critical"
```

Hide scheduler tick noise:

```logql
{compose_project="school_journal"} != "Scheduler tick"
```

All Docker logs from this Alloy config:

```logql

```

All logs from this server label:

```logql
{server="serverchibi2"}
```

If labels differ, use `Label browser` in Explore and inspect `compose_project`, `compose_service`, `container`, `server`, `source`, and `service_name`.

## Docker Logs Alloy Config

The Docker log pipeline should be appended to `/etc/alloy/config.alloy`. It uses the `loki.write.grafana_cloud_loki` block generated by Grafana Cloud.

```hcl
discovery.docker "school_journal" {
  host = "unix:///var/run/docker.sock"
}

discovery.relabel "school_journal" {
  targets = discovery.docker.school_journal.targets

  rule {
    source_labels = ["__meta_docker_container_label_com_docker_compose_project"]
    regex         = "school_journal"
    action        = "keep"
  }

  rule {
    source_labels = ["__meta_docker_container_name"]
    regex         = "/(.*)"
    target_label  = "container"
  }

  rule {
    source_labels = ["__meta_docker_container_label_com_docker_compose_project"]
    target_label  = "compose_project"
  }

  rule {
    source_labels = ["__meta_docker_container_label_com_docker_compose_service"]
    target_label  = "compose_service"
  }

  rule {
    target_label = "server"
    replacement  = constants.hostname
  }
}

loki.source.docker "school_journal" {
  host       = "unix:///var/run/docker.sock"
  targets    = discovery.relabel.school_journal.output
  labels     = { "source" = "docker" }
  forward_to = [loki.process.school_journal.receiver]
}

loki.process "school_journal" {
  forward_to = [loki.write.grafana_cloud_loki.receiver]

  stage.drop {
    older_than          = "120h"
    drop_counter_reason = "too_old_docker_log"
  }
}
```

Apply config changes:

```bash
cp /etc/alloy/config.alloy /etc/alloy/config.alloy.bak.$(date +%Y%m%d-%H%M%S)
alloy fmt --write /etc/alloy/config.alloy
systemctl restart alloy
sleep 10
systemctl status alloy --no-pager -l
```

## Docker Socket Permission

Alloy runs as the `alloy` user. Docker socket is usually owned by `root:docker`.

Check:

```bash
ls -l /var/run/docker.sock
id alloy
```

Fix:

```bash
usermod -aG docker alloy
systemctl restart alloy
sleep 10
id alloy
```

Expected group list includes `docker`.

## Common Problems

`permission denied while trying to connect to the Docker daemon socket`

Alloy cannot read Docker logs. Add `alloy` to the `docker` group and restart `alloy.service`.

`timestamp too old`

Alloy is trying to send old Docker log backlog. Keep the `loki.process` block with:

```hcl
stage.drop {
  older_than = "120h"
}
```

`cpufreq` errors in Alloy:

```text
collector failed ... name=cpufreq ... parsing "<unknown>"
```

This is common inside LXC/Proxmox. Add `"cpufreq"` to the `disable_collectors` list in:

```hcl
prometheus.exporter.unix "integrations_node_exporter"
```

Example:

```hcl
disable_collectors = ["ipvs", "btrfs", "infiniband", "xfs", "zfs", "cpufreq"]
```

`use of closed network connection`

This can appear during `systemctl restart alloy`. If it appears only at restart time and Alloy becomes `active (running)`, it is not a problem.

`No logs found` in Grafana:

1. Set time range to `Last 15 minutes`.
2. Generate fresh logs with `/healthz` and `/readyz`.
3. Try `{source="docker"}`.
4. Try `{server="serverchibi2"}`.
5. Open `Label browser` and inspect available labels.
6. Check Alloy logs for `permission denied`, `timestamp too old`, or HTTP `400/401/403/429`.

## Token Rotation

Rotate the Grafana Cloud token if it was exposed.

1. Create a new Grafana Cloud token with Alloy write permissions.
2. Edit the server env file:

```bash
nano /etc/systemd/system/alloy.service.d/env.conf
```

3. Replace only the token value.
4. Reload and restart:

```bash
systemctl daemon-reload
systemctl restart alloy
curl -fsS http://127.0.0.1:12345/-/ready
```

5. Delete the old token in Grafana Cloud.

## Useful Operational Queries

Recent app errors:

```logql
{compose_project="school_journal", compose_service="web"} |~ "(?i)error|exception|traceback|critical"
```

Scheduler activity without tick spam:

```logql
{compose_project="school_journal", compose_service="scheduler"} != "Scheduler tick"
```

Database warnings/errors:

```logql
{compose_project="school_journal", compose_service="db"} |~ "(?i)error|warning|panic|fatal|checkpoint"
```

Proxy requests and errors:

```logql
{compose_project="school_journal", compose_service="proxy"}
```

Manual stop markers:

```logql
{compose_project="school_journal"} |~ "(?i)manually stopped|operator_stop|failed"
```

## Stop And Resume Scheduler

Stop automatic scheduled jobs:

```bash
cd /opt/school_journal
docker compose -f docker-compose.server.yml stop scheduler
```

Start automatic scheduled jobs again:

```bash
cd /opt/school_journal
docker compose -f docker-compose.server.yml start scheduler
```

Check in Grafana:

```logql
{compose_project="school_journal", compose_service="scheduler"} |~ "(?i)scheduler|started|stopped|failed"
```
