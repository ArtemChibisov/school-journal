# Teachers Directory Data Contract

Status: agreed 05.10.2026.

Lives as the `teachers` worksheet in the same workbook as `subject_teachers`, described in
[subject_teachers_contract.md](subject_teachers_contract.md).

Related contracts:

- `docs/data_contracts/subject_teachers_contract.md`
- `docs/data_contracts/telegram_mapping_contract.md`

## 1. Зачем

Школа записывает преподавателя в журнале на том языке, на котором идёт обучение в классе:
в классах «К» — по-английски, в остальных — по-русски. Один и тот же человек поэтому
законно встречается под двумя написаниями:

```
Юлия Галкина     1А, 1И, 1Н, 2А, 2Г, 2Р, 3Д, 3Р, 3С
Yuliya Galkina   4К1, 4К2, 5К1, 5К2, 6К1, 6К2, 7К1, 7К2
```

Ни один журнал не сообщает, что это один человек. Справочник сообщает.

Без него система считает их двумя преподавателями: в таблице мониторинга человек двоится,
а напоминание о незаполненном журнале уходит на имя, за которым никого нет.

Альтернативой был перевод всех журналов на одно написание — около 120 листов правок,
с промежуточным состоянием, в котором человек раздваивается внутри одного журнала.
Справочник делает то же самое без единой правки.

## 2. Лист

Имя листа: `teachers`, строчными латинскими буквами, ровно так.

Строка 1 — заголовки. Колонки ищутся по имени, а не по позиции.

## 3. Колонки

```text
teacher_name_ru | teacher_name_en | is_active | notes
```

| Колонка | Обязательна | Может быть пустой | Описание |
| --- | --- | --- | --- |
| `teacher_name_ru` | да | да | Русское написание |
| `teacher_name_en` | да | да | Английское написание |
| `is_active` | да | нет | Работает ли преподаватель в этом году |
| `notes` | нет | да | Произвольный комментарий |

Обе колонки имени обязаны присутствовать, но каждая по отдельности может быть пустой.
Пустыми одновременно — не могут: строка без единого имени не описывает человека.

## 4. Какое написание обязательно

Зависит от того, где преподаватель ведёт:

- ведёт хотя бы в одном классе «К» — нужно `teacher_name_en`;
- ведёт хотя бы в одном остальном классе — нужно `teacher_name_ru`;
- ведёт и там и там — нужны оба.

Преподавателю, который никогда не заходит в класс «К», английское написание не нужно.
Из 73 человек в наборе 2026/27 таких 27, и ещё 8 — наоборот.

Проверить это можно только вместе с листом `subject_teachers`, поэтому отсутствие
написания — не ошибка самого листа `teachers`, а ошибка пары листов.

## 5. Сопоставление с журналами

`subject_teachers.teacher_name` и имя преподавателя внутри журнала должны совпадать с одним
из двух написаний. Совпадение точное после нормализации пробелов; регистр учитывается,
алфавит не подменяется.

Имя, которого нет в справочнике, — ошибка: система не знает, кто это.

## 6. Уникальность

Одно и то же написание не может принадлежать двум строкам: иначе по имени из журнала
нельзя определить человека.

Проверяется отдельно по русской и по английской колонке, с нормализацией пробелов и
регистра. Пустые клетки в проверке не участвуют.

Полные тёзки — редкий, но реальный случай; контракт их не поддерживает. Если встретятся,
различать придётся не именем, и это отдельное решение.

## 7. Флаг активности

`is_active` разбирается как в остальных таблицах: `yes/no`, `true/false`, `1/0`, `да/нет`,
native boolean.

Неактивный преподаватель остаётся в справочнике и продолжает сопоставляться с журналами
прошлых модулей, но не предлагается при создании новых.

## 8. Коды ошибок

| Код | Серьёзность | Область | Значение |
| --- | --- | --- | --- |
| `MISSING_REQUIRED_SHEET` | critical | workbook | Нет листа `teachers` |
| `INVALID_HEADERS` | critical | sheet | Нет обязательных колонок |
| `EMPTY_TEACHER_ROW` | critical | row | Обе колонки имени пустые |
| `INVALID_ACTIVE_FLAG` | critical | row | `is_active` не распознан |
| `DUPLICATE_TEACHER_NAME` | critical | row | Написание встречается дважды |
| `MISSING_RUSSIAN_NAME` | critical | row | Ведёт в обычном классе, русского написания нет |
| `MISSING_ENGLISH_NAME` | critical | row | Ведёт в классе «К», английского написания нет |
| `UNKNOWN_TEACHER` | critical | row | Имя из `subject_teachers` отсутствует в справочнике |
| `UNUSED_TEACHER` | info | row | Есть в справочнике, но нигде не ведёт |

## 9. Форма разбора

```json
{
  "teachers": [
    {
      "name_ru": "Юлия Галкина",
      "name_en": "Yuliya Galkina",
      "is_active": true,
      "notes": "",
      "row": 2
    }
  ],
  "errors": [],
  "warnings": []
}
```

## 10. Чего контракт не определяет

- привязку преподавателя к Telegram — отдельный контракт;
- должность, нагрузку и расписание;
- различение полных тёзок;
- написание на третьем языке.
