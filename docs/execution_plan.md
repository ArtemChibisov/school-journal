## 1. Как мы работаем

Главное правило: **отправка в `main` автоматически обновляет боевой сервер школы**. Поэтому в `main` ничего не попадает напрямую.

Цикл одной задачи:

1. Новая ветка под задачу
2. Код и тесты
3. Прогон тестов локально
4. Проверка глазами в браузере локально
5. Отправка ветки и pull request — запускается CI, деплой не запускается
6. Слияние после зелёного CI — вот здесь происходит деплой

Команды:

```bash
git switch -c название-задачи
```

```bash
./.venv/Scripts/python.exe manage.py test
```

```bash
git push -u origin название-задачи
```

```bash
gh pr create --fill
```

```bash
gh pr checks --watch
```

```bash
gh pr merge --squash --delete-branch
```

## 2. Как посмотреть локально в браузере

Запуск:

```bash
./.venv/Scripts/python.exe manage.py runserver
```

Открыть в Chrome: `http://127.0.0.1:8000/`

Вход под своим локальным пользователем. Если пароль забыт:

```bash
./.venv/Scripts/python.exe manage.py changepassword artchibisov
```

Остановить сервер: `Ctrl+C` в терминале.

Важно про локальную работу:

- база локальная, SQLite, к серверу отношения не имеет;
- Google подключён по-настоящему: режим `oauth_owner`, токен и `client_secret` лежат в `creds/google/`. То есть импорт из реальных таблиц проверяется локально;
- если модели менялись, перед запуском нужно `manage.py migrate`.

## 3. Правило: у каждой фазы есть экран

Фаза считается завершённой, когда результат можно увидеть в браузере, а не только в выводе команды.

Из этого следует порядок внутри фазы: сервис, тесты, **экран**, и только потом следующая фаза. Команда в терминале допустима как черновик, но она не закрывает фазу.

## 4. Перенос на школьный сервер

Переезд завершён 21.09.2026. Все фазы закрыты.

| Фаза | Что | Статус |
| --- | --- | --- |
| A | Репозиторий `proektordocs-ops/school-journal` | Готово |
| B | Разведка сервера: Caddy, свободный порт 8090 | Готово |
| C | Правки кода под сервер | Готово |
| D | Папка, `.env.production`, учётные данные Google | Готово |
| E | Первый запуск контейнеров | Готово |
| F | Домен `reports.projector-school.info`, Caddy, сертификат | Готово |
| G | Автодеплой через GitHub Actions | Готово |
| H | Google OAuth redirect URI, Telegram webhook | Готово |

Детали и команды: [migration_runbook.md](migration_runbook.md).

Сайт доступен по `https://reports.projector-school.info`, сертификат выпущен Caddy автоматически. Приложение слушает только `127.0.0.1:8090`, наружу его пускает системный Caddy, соседние сервисы не затронуты.

Откат конфига Caddy лежит на сервере в `/etc/caddy/Caddyfile.before-reports`.

Google подключён на проде: режим `oauth_owner`, токен с `refresh_token` в `/app/creds/google/rt.json`. Telegram-вебхук указывает на новый адрес, админ-чат получает сводки.

## 6. Как проверять фазы в браузере

### Готово и проверяемо сейчас

| Что смотреть | Где | Что должно быть |
| --- | --- | --- |
| Страница входа | `/accounts/login/` | Форма входа, при неверном пароле понятная ошибка, после входа возврат на запрошенную страницу |
| Выход | Кнопка `Выйти` в шапке | Возврат на страницу входа |
| Google-подключение | Меню слева, `Google-подключение` | Режим доступа, наличие токена, зелёная плашка «Google подключён» |
| Проверка доступов | Там же, кнопка `Проверить доступы` | Таблица из 13 строк со статусами: доступно, ошибка, не заполнено |
| Понятность ошибок | Там же, при сломанной ссылке | Текст для человека, без кодов и идентификаторов файлов |
| Технические логи | Ссылка `Технические логи проверки` | Карточка запуска с подробностями для администратора |
| Настройка учебного года | Меню слева, `Учебный год` | Форма со всеми ссылками, подсказка чего не хватает для создания журналов |
| Проверка ссылок | Там же, вставить папку в поле таблицы | Ошибка у самого поля человеческим текстом |
| Импорт состава классов | Меню слева, `Состав классов` | Ссылка на таблицу, кнопки `Пробный прогон` и `Импортировать` |
| Отчёт импорта | Там же, после запуска | Счётчики, список проблем человеческим текстом, таблица заведённых классов |
| Пробный прогон ничего не меняет | Там же | Пометка «пробный», в счётчиках синхронизации нули |

Учебный год создаётся на экране `Учебный год`, кнопка `Создать новый год`. Django-админка для этого больше не нужна.
